# 逐梦使用政策

**生效及最后更新日期：2026 年 7 月 23 日**

本政策适用于逐梦的全部控制台、API、模型、搜索、工具和相关服务。您还必须遵守适用上游供应商的政策；限制不一致时，以更严格者为准。

## 1. 禁止用途

不得使用服务实施、促成、指导或实质性协助以下活动：

- 违法活动、规避制裁或出口管制、洗钱、欺诈、盗窃、诈骗、钓鱼、垃圾信息、虚假身份或冒充；
- 儿童性剥削、非自愿色情、人口贩运、性暴力或针对未成年人的不当内容；
- 恐怖主义、暴力极端主义、可信的伤害威胁，或开发、获取、部署大规模杀伤性武器；
- 未经授权侵入系统、窃取凭据、恶意软件、勒索软件、DDoS、破坏服务、绕过访问控制或隐匿攻击来源；
- 在无授权情况下搜集、推断、出售或公开敏感个人信息，进行人肉搜索、持续跟踪、侵入性监控或受限制的生物识别；
- 侵犯知识产权、隐私、保密义务、人格权或其他第三方权利；
- 规避模型安全措施、逐梦或上游的额度、区域、速率、并发、身份、计费或反滥用控制；
- 操纵舆论、虚假互动、批量不真实账号、选举干预，或以欺骗方式生成并冒充真人发布内容；
- 在无合格人工复核、告知和申诉机制的情况下，用于就业、住房、教育、信贷、保险、医疗、法律执法或其他高影响自动决策；
- 提供未经适当资质和人工审查的个性化医疗、法律或金融结论，或保证输出准确、安全或盈利；
- 交易或推广法律禁止或严格监管的商品和服务。

## 2. 平台与凭据滥用

禁止转售、共享或公开 API Key；批量注册、套取优惠、拒付后重开账户；制造虚假流量；探测或利用非本人系统；抓取控制台；逆向底层模型；构建竞争性凭据市场；或干扰其他用户的正常服务。

## 3. 安全研究

经资产所有者明确授权、在受控范围内开展的防御性研究、漏洞验证、恶意样本分析和教育用途可以接受。研究不得访问无关数据、造成持久影响、扩大权限、公开未修复漏洞或攻击生产用户。我们可要求您提供授权和测试计划。

## 4. 内容与人工监督

您必须评估输入和输出，配置适当的内容过滤、年龄保护、访问控制、日志和人工复核。不得向用户谎称 AI 输出由真人制作或获得逐梦、上游供应商背书。高风险场景不得把模型输出作为唯一依据。

## 5. 执行

我们可使用自动检测、抽样和人工审查识别风险，并可拒绝单个请求、降速、隔离路由、要求验证、暂停 API Key、冻结账户或终止服务。严重或紧急风险可不经通知处理；必要时我们可保存证据并依法响应上游、受害方或主管机关。
